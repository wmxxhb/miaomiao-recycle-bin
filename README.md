# 喵喵回收站

一个 Windows 桌面精灵：把文件拖给喵喵，送入系统回收站；右键与它聊天，回复显示在头顶的漫画大气泡里。

桌面版 **0.5.2** · Windows 10/11 · Electron + Three.js · MIT（仅项目代码）

[下载安装程序（EXE）](https://github.com/wmxxhb/miaomiao-recycle-bin/releases/latest/download/Miaomiao-Recycle-Bin-Setup-0.5.2.exe) · [下载便携版（ZIP）](https://github.com/wmxxhb/miaomiao-recycle-bin/releases/latest/download/Miaomiao-Recycle-Bin-0.5.2-Windows-x64.zip)

Windows 10/11 64 位。发布包已包含程序、三种形态和动作资源，无需安装 Node.js、游戏或另外准备素材。AI 对话需要你自己的 API 配置。

## 功能

- **三种形态**：喵喵 → 喵呜 → 魔力猫；支持投喂成长与手动切换，累计进度保留。
- **文件投喂**：拖入文件或文件夹，通过 Windows 回收站回收；成功后核对原路径并通知桌面刷新。一批至少成功一项记一次成长。
- **成长设置**：默认累计 10 / 30 次进化，两级次数可调整；进度条放在设置里。
- **桌面互动**：轻点随机动作，按住拖动位置。拖动保持大小，缩放由设置中的 50%–200% 滑块控制。
- **60 FPS 渲染目标**：实时骨骼插值、眼睛与嘴部表情曲线，实际帧率取决于显卡和显示环境。
- **漫画对白**：右键精灵打开脚边输入框，完整回复在同一个漫画大气泡内逐渐显示，长文可滚动。
- **AI 对话**：DeepSeek、OpenAI、Claude，以及兼容这三种接口格式的自定义服务；支持连接测试、获取模型列表、流式回复、停止与重新回答。
- **随形态变化的人设**：保留同一段对话，默认称呼“小洛克”，支持昵称与回复偏好；完整回复以“喵”收尾。
- **本机记录**：新建、恢复、删除对话，复制回复，导出 Markdown / JSON；API 密钥使用 Windows 本机加密保存。
- **精灵动作室**：三种形态各 27 段动作；搜索、分类、播放/暂停、逐帧、速度、循环、原地播放、眼神和视角调整。收藏与用途备注独立保存，属于预览清单。
- **托盘控制**：打开设置、输入框、聊天记录、动作室，切换形态、显示/隐藏、召回和退出。

## 使用指南

### 下载与启动

- **安装版**：下载上方 EXE，运行安装程序，随后从桌面或开始菜单打开“喵喵回收站”。无需管理员权限。
- **便携版**：下载上方 ZIP，完整解压到普通文件夹，再双击其中的 `喵喵回收站.exe`。请保留旁边的文件和目录，不要只复制 EXE。
- 更新前先通过托盘退出旧程序。便携版可解压到新目录；设置和聊天保存在当前 Windows 用户目录中。
- 初次启动先轻点精灵试试；右键系统托盘图标可打开设置。

### 桌面操作

| 操作 | 效果 |
| --- | --- |
| 单击精灵 | 播放点击动作 |
| 按住并移动 | 拖动位置，松开继续动画 |
| 拖入文件/文件夹并松开 | 投喂到系统回收站 |
| 右键精灵 | 打开输入框 |
| Enter / Shift+Enter | 发送 / 换行；输入法选字时不误发 |
| Esc / 输入框关闭按钮 | 收起并保留本次运行的草稿 |
| 气泡内滚动 / × | 阅读长回复 / 收起本条气泡 |
| 气泡“停止” | 停止生成并保留已收到文字 |
| 右键系统托盘图标 | 打开设置、记录、动作室及其他菜单 |

精灵本身没有名字标签或设置按钮。托盘图标可能藏在任务栏的“显示隐藏的图标”里。气泡与输入框跟随精灵，靠近屏幕边缘时自动调整位置。

### 形态与动作

设置中选择“投喂成长”或“手动形态”。修改进化次数后点击保存；累计次数以成功批次计数，恢复回收站中的文件不会扣除成长。

| 触发 | 动作池 |
| --- | --- |
| 平时 | 待机 |
| 投喂成功 | 开心、放松、炫耀、技能三起手 |
| 点击 | 警觉、生气、惊恐、开心、放松、震惊、炫耀、倒地、技能三起手、眩晕、受击 |
| 挂机 25–45 秒后 | 警觉、开心、放松、伤心、入睡→睡眠→醒来、行走、睡眠站姿、落地 |

眩晕、行走、睡眠站姿、落地和睡眠循环持续随机 5–10 秒，结束回到待机。点击和投喂可以打断挂机动作；行走在原地播放。动作室中的用途标记用于挑选预览，不会自动修改桌面动作池。

### 配置 AI

1. 右键托盘 → **打开设置 → AI 对话**。
2. 选择厂商，填写服务地址、模型和 **API Key 密码框**。使用自定义服务时选择相应接口格式。
3. 点击测试连接或获取模型列表，再保存。保存后密钥输入框清空，不会回填已存密钥。
4. 右键精灵开始聊天；托盘中的“查看聊天记录”可管理、导出对话。

远程 API 必须使用 HTTPS，本机兼容服务可使用 localhost / 127.0.0.1 的 HTTP 地址。切换域名或端口后需重新填写密钥；请求不会跟随重定向。Claude 的 API 版本与 Workspace ID 按服务要求填写；模型预设不代表账号一定有权限。

设置还可调整昵称、回复偏好、上下文轮数、回复长度、气泡和情绪动作。不同形态沿用当前对话；新对话拥有独立上下文。AI 仅接收你发送的聊天、当前人设与必要上下文，投喂文件不会发送给 AI，聊天不能执行电脑操作。

### 文件恢复与本机数据

投喂会实际移除原位置的文件。需要找回时，打开 **Windows 回收站 → 还原**。本程序没有永久删除接口；系统不允许回收或原路径仍存在时，会报告失败。程序目录、应用数据及常见系统目录受到投喂保护。

数据保存在当前 Windows 用户的 `%APPDATA%\喵喵回收站\`：

| 文件 | 内容 |
| --- | --- |
| `state.json` | 形态、成长、缩放与位置 |
| `ai-settings.json` | 服务地址、模型与回复偏好 |
| `ai-secrets.json` | Windows 加密后的凭据，与服务来源绑定 |
| `chat-history.json` | 本机聊天文字 |
| `recycle-log.json` | 最近投喂的路径与结果 |
| `action-choices.json` | 应用启动的动作室收藏与用途备注 |

聊天与投喂日志是本机明文，请按个人文件保管。导出对话不会带出配置中的密钥，但会包含你主动输入的聊天内容。备份前退出程序；加密密钥通常不能搬到其他 Windows 用户或电脑使用。加密不可用时拒绝保存密钥，不降级为明文。更多说明见 [安全与隐私](SECURITY.md)。

## 简单技术说明

| 部分 | 作用 |
| --- | --- |
| Electron 主进程 | 托盘、窗口、回收站、配置与 AI 请求 |
| 隔离的渲染窗口 | 展示精灵、设置、输入框、气泡与记录；无 Node.js 权限 |
| Three.js | 加载本机 GLB，播放骨骼动画与表情图集 |
| `native/*.cs` | 用 Windows 物理像素移动窗口、通知资源管理器刷新 |
| 本机动作室 | 只监听 `127.0.0.1`，检查 Host / Origin，按素材清单提供文件 |

渲染器通过有限的 preload 接口请求主进程操作；主进程检查请求窗口和主框架。模型回复以纯文本呈现。AI 密钥由主进程加解密并发送到用户配置的服务，不回传界面；文件投喂与 AI 请求各自处理。
